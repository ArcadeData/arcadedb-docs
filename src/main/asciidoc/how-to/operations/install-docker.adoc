[[install-docker]]
==== Installation with Docker

ArcadeDB is published as a Docker image on Docker Hub: https://hub.docker.com/r/arcadedata/arcadedb[arcadedata/arcadedb].
The image runs on Java 25 (`eclipse-temurin:25-alpine`) and is built for `linux/amd64` and `linux/arm64`.

To pull a specific release:

[source,bash,subs="+attributes"]
----
docker pull arcadedata/arcadedb:{revnumber}
----

The JVM image is published under these tags:

[%header,cols="1,3"]
|===
| Tag | Content
| `<version>` (for example `{revnumber}`) | The release with that version number.
| `latest` | The most recent build of the `main` branch, pushed on every merge. It is a development snapshot, not the latest release, so pin a version tag in production.
| `<next-version>-SNAPSHOT` | The same development build, tagged with the version under development.
|===

A Java 17 image, built from the separate `java17` branch, is published on GitHub Container Registry with a `-java17` tag suffix, usually some time after the main release:

[source,bash,subs="+attributes"]
----
docker pull ghcr.io/arcadedata/arcadedb:{revnumber}-java17
----

An experimental GraalVM native image of the server is also published, under the `-native` tags (`<version>-native` for a release, `latest-native` for the nightly build of `main`).
It starts faster and needs less memory, but leaves out Gremlin and has other limitations: see <<native-image>>.

To run the container, configure it and persist its data, see <<docker>>.
