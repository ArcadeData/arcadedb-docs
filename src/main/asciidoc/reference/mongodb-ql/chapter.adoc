=== MongoDB Query Language Reference
endif::[]

ifdef::site-gen-antora[]
ArcadeDB speaks MongoDB in two ways. You can run MongoDB Query Language queries against any database by passing `mongo` as the query language to the Java API, the HTTP API or the Postgres driver. You can also enable the MongoDB protocol plugin, which listens on port 27017 so that existing MongoDB drivers and `mongosh` connect to ArcadeDB directly. The reference below covers the `arcadedb-mongodbw` dependency for embedded use, server setup, the supported commands, authentication and index management.
endif::[]
