=== Java API Reference
:description: ArcadeDB Java API reference: database and async APIs, schema, events, embedded documents, the Select API, batch importer, vectors, and the remote and gRPC clients.

ifdef::site-gen-antora[]
The Java API gives direct access to ArcadeDB from the JVM, either embedded in the same process or as a client of a remote server. This reference documents the `Database` interface and its asynchronous variant, schema management, database events, embedded documents, the fluent Select API, the batch importer for bulk loads, vector indexes, and the remote and gRPC clients.
endif::[]
