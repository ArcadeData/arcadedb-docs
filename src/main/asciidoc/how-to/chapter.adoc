== How-To Guides
:description: ArcadeDB how-to guides: data modeling, BI and analytics integrations, server operations such as backup, HA and Kubernetes, and migrating data into ArcadeDB.

How-to guides are task-oriented recipes for an ArcadeDB you already have running.
Each one answers a single question, such as how to add a full-text index, plug in Grafana, back up a database, run a cluster on Kubernetes or import a Neo4j export, and links to the reference pages for every option it uses.
For a first walkthrough start with the tutorials, and for the ideas behind the steps read the concepts.
