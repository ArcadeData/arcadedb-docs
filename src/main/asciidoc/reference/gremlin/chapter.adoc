=== Gremlin Reference
endif::[]

ifdef::site-gen-antora[]
ArcadeDB supports Apache TinkerPop Gremlin 3.7 both as an embedded query engine and through the bundled Gremlin Server on port 8182. You can run traversals from the Java API, the HTTP API or the Postgres driver, or point any TinkerPop-compatible client at the Gremlin Server. The reference below covers the `arcadedb-gremlin` dependency, the `ArcadeGraph` entry point, transactions, multi-database setup and the security settings for the Gremlin engine.
endif::[]
