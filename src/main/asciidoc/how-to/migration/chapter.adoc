=== Migration & Import
:description: Migrate data into ArcadeDB: the general importer, the graph importer, JSON import, and dedicated importers for OrientDB databases and Neo4j exports.

ifdef::site-gen-antora[]
Moving an existing dataset into ArcadeDB rarely needs custom code. The general importer loads CSV, JSON, JSONL, XML, RDF, GraphML and GraphSON files into documents, vertices and edges, and the graph importer bulk-loads graphs with millions of vertices and edges from CSV, XML and JSONL files. Dedicated importers read OrientDB database exports and Neo4j exports, keeping types, properties and relationships. Each guide below shows the command to run, the options that control the mapping, and how to verify the result.
endif::[]
