== Tools Guide
:description: ArcadeDB tools: Studio, the web-based workbench, the Swagger UI for the HTTP API, the interactive console, and third-party tools that work with ArcadeDB.

ifdef::site-gen-antora[]
ArcadeDB ships with tools for working with databases without writing application code. Studio is the web workbench for running queries, exploring graphs and administering the server. The Swagger UI documents and exercises the HTTP API from the browser, and the console is an interactive shell for scripts and automation. This chapter also lists third-party tools, such as graph visualizers and database IDEs, that work with ArcadeDB.
endif::[]
