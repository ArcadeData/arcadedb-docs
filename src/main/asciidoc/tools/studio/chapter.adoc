=== ArcadeDB Studio
endif::[]
:description: ArcadeDB Studio, the web workbench bundled with the server: run queries, browse data, manage databases and time series, administer the server and profile queries.

ifdef::site-gen-antora[]
ArcadeDB Studio is the web workbench bundled with every server, available at port 2480 in a browser. It lets you run SQL, Cypher, Gremlin and other queries and see the results as a table, graph, chart, JSON document or execution plan, browse and manage databases, explore time series, monitor and administer the server, profile slow queries, manage users and cluster nodes, and call the HTTP API. The pages below describe each panel in turn.
endif::[]
