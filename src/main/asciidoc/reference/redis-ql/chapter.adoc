=== Redis Protocol Reference
endif::[]

ifdef::site-gen-antora[]
ArcadeDB Server implements a subset of the Redis wire protocol, so any Redis client can connect to it on port 6379 once the Redis plugin is enabled. Commands work in two modes: transient commands keep key/value pairs in server memory only, which suits data such as user sessions, while persistent commands read and write documents, vertices and edges stored in the database. The reference below covers the `arcadedb-redisw` dependency, plugin installation and the list of supported commands.
endif::[]
