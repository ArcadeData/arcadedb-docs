=== GraphQL Reference

ifdef::site-gen-antora[]
ArcadeDB runs GraphQL as a query language engine on top of its own types. You can send GraphQL from the Java API, the HTTP `/query` and `/command` endpoints, or the Postgres driver. The reference below explains the `arcadedb-graphql` dependency, how to define GraphQL types that map to ArcadeDB document and vertex types, query arguments and variables, fragments, and the directives that embed SQL, Cypher or Gremlin inside a GraphQL query.
