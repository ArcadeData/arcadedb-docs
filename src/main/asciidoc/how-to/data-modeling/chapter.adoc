[[data-modeling]]
=== Data Modeling

ifdef::site-gen-antora[]
These guides show how to model data for specific query patterns in ArcadeDB. They cover full-text indexes for keyword search, geospatial indexes and functions for location queries, materialized views that keep precomputed results up to date, graph OLAP for analytical traversals over large graphs, and vector embeddings for similarity search. Each guide includes the schema to create and the queries that use it.
endif::[]
